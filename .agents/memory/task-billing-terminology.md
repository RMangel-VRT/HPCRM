---
name: Task billing terminology boundaries
description: Why client ticket labels and server/campaign terminology are intentionally not fully synchronized.
---

Use Contract/Billable terminology for Task tickets. Do not assume that changing the client billing label authorizes changing the corresponding server catalog label or campaign category terminology.

**Why:** The approved web-client addendum deliberately required the client to say Billable while the server retained its legacy billing label for its existing tests. Campaign categories are a separate domain; only campaign text describing generated tickets changes to Billable Task(s).

**How to apply:** When synchronizing catalogs or searching for residual legacy terminology, distinguish ticket-facing labels from server compatibility labels and campaign category names/values. Preserve these boundaries unless a later request explicitly changes them.
