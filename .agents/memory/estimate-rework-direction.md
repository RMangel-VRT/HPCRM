---
name: Estimate rework direction
description: November 19 decisions for the single-page estimate workflow and proposal retirement.
---

The estimate builder is the one place to write, price, illustrate, preview,
send and track estimates. Draft downloads are clean and non-mutating; the first
edit on a current sent/declined version asks before revising, while accepted
versions keep the existing change-order path. Show version numbering only after
a second version exists. Keep mark-sent without emailing for hand delivery.

**Why:** The user found that the separate proposal step, cover and manual
version ceremony added work without value. They want photos and plant pictures,
not a second document editor.

**How to apply:** Build version behavior, line editing and the one-page layout
first; add version-owned plants/photos and worksheet generation, then CRM email.
Retire proposal writes only after those replacements work. Keep historic
proposals, files and worksheet snapshots readable, with existing download and
confirmed delete. Do not add a cover or Visual Scope to estimates, migrate
proposal files, or change invoices. W1 continues to govern live work location.

Do not describe historical standalone estimate PDFs as archived originals
unless the application actually stored the sent attachment. The approved
version labels depend on how many versions exist at render time, and W1 location
remains a live read-through. The approved mockup leaves the estimate-wide title
editable only on a draft; first-edit revision applies to version-owned content.

**Why:** Frozen commercial contents and the exact PDF the customer received are
different records, and title is not owned by each version.

Reference counting for estimate photo retention needs to include both estimate
versions and generated worksheets. An estimate or its draft can disappear while
a crew still needs its worksheet, including every image that worksheet captured.

**Why:** The worksheet is an intentional snapshot with nullable source links,
not a live view of the estimate. Deleting the source is not consent to delete
the worksheet or its files.

**How to apply:** If adding cleanup, verify both kinds of references before
deleting accepted photo bytes. Do not let proposal retirement sweep this media.
