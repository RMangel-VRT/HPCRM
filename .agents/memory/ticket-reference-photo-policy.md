name: Ticket reference photo policy
description: Photo-capable ticket creation must have matching post-creation reference-photo access.
---

Every ticket type that accepts photos during creation must also allow adding them after creation, including when it started without any photos. The Photos section should remain discoverable instead of appearing only after the first attachment.

**Why:** On November 16, 2026 the user found an Estimate Request with no way to add missing site photos and explicitly requested parity across photo-capable ticket types.

**How to apply:** Preserve ticket-role and company permissions, append without replacing existing reference photos, and keep reference attachments separate from completion/job-recap photos. Do not add status-dependent restrictions or broaden RFP creation's photo policy without a separate request.
