name: Ownership map check
description: Check the agreed owner before adding facts.
---

Before adding a table or column, check `docs/data-ownership-map.md` for the owner.

**Why:** Randy's one-owner rule requires every other copy to be a deliberate printed snapshot or named automatic mirror; independent copies drift.

**How to apply:** Identify the owner and classify any copy before planning schema or writer changes. Preserve frozen values until readers are retired in a separate reviewed slice.
