Customer Contracted Services documents follow SC3's supported service list rather than reproducing the sample's separate bed/hard-surface weed-control row or fixed service total.

**Why:** On November 13, 2026 the owner explicitly chose the SC3 list when the reference PDF and catalog differed.

**How to apply:** Treat the sample as a visual reference; derive services/counts from the selected-season fulfillment owner and never invent a new service to match it.

Route services with no count print and do not block. Included and When use the scope monthSpread frequency phrase. Without spread, use the recurring calendar pattern only if it contains no digits; otherwise print “As scheduled.” Completed uses “N done” once positive, with no owed denominator.

**Why:** The owner clarified that no-count route services are normal; irrigation inspection is “Monthly.” This explicitly overrides SC3's original blanket pattern-text prohibition and no_count blocking.

**How to apply:** Block only round/checklist no_count, needs_rounds, invalid_count or duplicate_lines, and route invalid_count or duplicate_lines. Inspect issue flags so another primary display status cannot conceal a blocker; do not alter demand/count ownership to make the document print.
