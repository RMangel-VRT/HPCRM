# Replit Prompt — Communications Rework, Slice 4 (Cleanup & Deprecation)

## Context

Slices 1-3 are complete. The unified Communications page at `/dashboard/communications/:tab` is live with Inbox, Sent, Unsorted, and All Communications sub-tabs, all per-user-scoped. The standalone `UnsortedInboxPage` still exists as a thin back-compat wrapper, and the old `/dashboard/communications/unsorted` route still resolves. This is **Slice 4 of 4** — cleanup. Goal: remove the deprecated paths, dead components, and any internal links that still point at them, and add small UX polish that depends on having all the pieces wired up.

## What this slice does

1. Deletes `client/src/pages/UnsortedInboxPage.tsx` (its body now lives in `UnsortedTab.tsx`).
2. Replaces the route with a redirect.
3. Audits internal links (notifications, customer cards, automation result toasts, etc.) for any URL pointing at the old paths and updates them.
4. Removes the now-orphaned `MailboxAccountsSettingsPage` link to `/dashboard/communications/unsorted` if it exists.
5. Adds a "Compose" entry point that's currently scattered — single button in the toolbar that opens the `LogCommunicationForm` pre-scoped to the current viewAs mailbox.
6. Adds light analytics: server-side log line on each tab's GET counting items returned, so we can see if Inbox/Sent volumes look right post-Slice-2.

## Route changes

`client/src/App.tsx`:

```tsx
// Remove:
<ProtectedRoute path="/dashboard/communications/unsorted" component={UnsortedInboxPage} ... />

// Add (matches before the :tab? route to avoid collision):
<Route path="/dashboard/communications/unsorted">
  <Redirect to="/dashboard/communications/unsorted" />   {/* the new tab path */}
</Route>
```

(The redirect target is the same string but it now resolves to the unified page's `:tab` param being `"unsorted"`, since the standalone page no longer exists. Wouter routes the longer prefix to the same component.)

Remove the lazy import of `UnsortedInboxPage`.

## Internal-link audit

Grep for these strings and fix every hit:
- `/dashboard/communications/unsorted` (any path that built it manually) → keep, redirect handles it, but prefer linking to the new tab path directly
- `UnsortedInboxPage` import — should only be in App.tsx and the deleted file
- Notification deep links generated by `due-date-notifications.ts` or `automationService.ts` that point at communications — should target the new Inbox tab with a query param (e.g., `?focus=<communicationId>`); add `focus` query support in `InboxTab.tsx` if not already there (auto-scrolls and highlights).

## "Compose" affordance

Currently composing a new communication is done from inside customer detail. Add a "Compose" button to the unified page toolbar:
- Opens `LogCommunicationForm` in a modal (already exists).
- Pre-fills `mailboxAccountId` with whatever the `viewAs` resolves to:
  - viewAs is a single mailbox → that mailbox
  - viewAs is "self" → the user's primary personal mailbox (if they have one)
  - viewAs is "all" or another user → field is empty, user picks
- After successful send, invalidates the Sent tab query so the new row appears immediately.

Hide the Compose button for users with no connected mailbox.

## Server-side observability

In `server/routes.ts` and `server/routes/unsortedEmails.ts`, after handling each list endpoint, log:

```
[communications.list] user=<id> role=<role> tab=<inbox|sent|unsorted|all> viewAs=<value> returned=<count> totalAvailable=<count>
```

Keep at info level; don't log subjects or addresses. This lets us spot-check that scoping is working in production without instrumentation overhead.

## Empty state copy polish

Now that everything's wired together, tighten the empty states:
- Inbox empty + user has no connected mailbox → CTA links directly to the mailbox-connect flow on `MailboxAccountsSettingsPage`.
- Inbox empty + user has a mailbox but no recent mail → friendlier message: "Nothing new in the last 30 days. Try widening the date range."
- Unsorted empty + user has triaged things today → small celebration: "All caught up. You routed N emails today."

Don't ship anything cute that requires real data tracking we don't have yet — the "N today" can come from `unsorted_emails.resolvedAt > startOfDay AND resolvedByUserId = me`.
