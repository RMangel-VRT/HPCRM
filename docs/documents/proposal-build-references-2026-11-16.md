## Key changes in this reference

- White proposal cover replaces the solid-green cover. With an image, use an
  edge-to-edge image below the header; without an image, omit the empty box and
  use larger type, work location and a proposal-total box.
- Cover mountains match the acceptance-page strip. The cover has the company
  address footer but no page number, and is excluded from page counts.
- Opening details, estimate-owned scope, pricing, Plants, terms, conditional plant
  warranty and acceptance flow continuously without forced section page breaks.
  Cover, each Visual Scope figure and each photo attachment page start new pages.
- Keep pricing table headers repeating, totals unbroken and the acceptance
  signature box together.
- Plants becomes one thumbnail table sourced from estimate plant lines, replacing
  separate palette pages and plant schedule; optional palette introduction stays.
- Large photo attachments use two photos per page; grid uses four. Captions
  appear above the images.
- Proposal scope, prices and totals belong to the referenced estimate version.
  Keep one acceptance. Do not restore the removed “By category” summary.
- Use the CRM's capitalized unit list, shared document renderer, visual tokens
  and page rules specified in the uploaded rules rather than a second template.
