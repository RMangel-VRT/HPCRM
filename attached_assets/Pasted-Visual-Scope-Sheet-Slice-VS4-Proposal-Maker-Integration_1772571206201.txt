Visual Scope Sheet — Slice VS4 (Proposal Maker Integration) — Submit This Whole Block
Goal

Integrate Visual Scope Sheets into Proposal Maker so a proposal can include professional “Visual Scope” visuals. Users must be able to attach one Visual Scope Sheet to a proposal draft and have the Proposal PDF include:

A combined visual scope page (base + markup + legend)

Optional appendix pages containing Base-only and Overlay-only images (separated layers)

No new version-freezing logic is added in this slice (that is VS5).

Guardrails (What NOT to build yet)

Do not add proposal/visual-scope version freezing yet (VS5)

Do not add multiple visual scopes per proposal yet (one per proposal only in VS4)

Do not add templates, emailing, approvals, or automation

Do not introduce GIS/measurements

Keep layout simple and reliable

Requirements
1) Proposal Draft: Add Visual Scope Attachment (One Per Proposal)

On the Proposal Draft page, add a section: Visual Scope

Users (Admin + Office only) can:

Attach Visual Scope Sheet (select from existing VS drafts for that customer)

View/Open the selected VS draft in a new tab

Remove the attachment

Rules:

Only Visual Scope Sheets belonging to the same customer may be attached

Only one Visual Scope Sheet can be attached to a proposal in VS4

If a VS draft has no base image, it cannot be selected (disabled with tooltip)

2) Data Linking (Minimal)

Store on the proposal draft record:

visualScopeSheetId (nullable)

No other proposal schema changes required.

3) Proposal PDF Output: Add Visual Scope Pages

Update proposal PDF generation so when a proposal has an attached Visual Scope Sheet:

Insert location

Insert Visual Scope pages after the branded cover/scope pages and before the QuickBooks estimate pages.

Final order becomes:

Branded cover/scope

Visual Scope (combined page)

Optional appendix: Base-only page

Optional appendix: Overlay-only page

QuickBooks estimate PDF pages

Photo appendix (proposal photos) if present (existing behavior)

Visual Scope pages included

Always include:

Combined image page

Optionally include (controlled by checkboxes on Proposal Draft page):

Base-only page

Overlay-only page

4) Visual Scope Render Source (Server-Side, Deterministic)

All images included in the proposal must be generated via VS3 server-side export endpoints (not client rendering):

/export/combined

/export/base (optional)

/export/overlay (optional)

Use a consistent width target for proposal insertion (recommended: 2000–3000 px) to balance quality and file size.

5) Visual Scope Page Layout (Professional + Stable)

Each Visual Scope page must be clean and print-ready:

Page title at top: “Visual Scope” (or “Visual Scope — Base Image”, “Visual Scope — Overlay”)

Image centered on the page

Maintain margins; do not crop the image

Scale image to fit page content area while preserving aspect ratio

Optional small caption line under the image:

VS title + date

No overlap with headers/footers

6) Failure Handling

If the attached Visual Scope Sheet cannot be rendered (missing base image, export failure):

Proposal PDF generation must fail with a clear error message

Do not generate partial PDFs silently

7) Permissions

Admin + Office: can attach/remove, and generate proposal PDFs including visual scopes

Other roles: no access

Acceptance Tests

Proposal draft allows selecting a Visual Scope Sheet for the same customer

VS without base image cannot be selected

Selected VS shows link to open the VS draft

Proposal PDF includes combined Visual Scope page in correct order (before estimate)

Base-only and Overlay-only pages appear only when enabled

Visual Scope image renders with correct aspect ratio and readable quality

Proposal generation fails cleanly if VS export fails

No Visual Scope attached → proposal PDF behavior remains unchanged

Done Definition

Users can attach a single Visual Scope Sheet to a Proposal Draft and generate a proposal PDF that includes a professional Visual Scope combined page (and optional separated base/overlay appendix pages), inserted in the correct position with deterministic server-side rendering.
