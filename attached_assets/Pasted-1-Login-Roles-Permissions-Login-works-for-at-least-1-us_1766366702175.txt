1) Login, Roles, Permissions

Login works for at least 1 user in each role: Admin, Office, Ops, Viewer.

Role restrictions are correct:

Only Admin can access Settings.

Office can edit CRM + contracts + services + rates.

Ops can update tickets assigned to them (and only what they’re allowed to).

Viewer is read-only everywhere.

Try to access a restricted page directly via URL → confirm it blocks correctly.

2) CRM Customer Records

Create a new customer with required fields.

Edit customer details → save → refresh → data persists.

Search for the customer by name → returns correctly.

Status changes (Prospect/Active/Inactive) work and persist.

3) Contracts & Signed Contract PDF

For a customer:

Create a contract (Maintenance, Chemical, etc.).

Confirm date validation works (start < end).

Enter monthly billing values and confirm:

Annual total equals sum of months.

Revenue projection updates.

Upload a signed contract PDF:

View and download work.

File is stored under the correct customer/contract.

Non-PDF upload is rejected (if that rule exists).

Replace the PDF (if supported) → new file is now current.

Refresh page → everything persists.

5) Revenue Projection

Confirm customer revenue view matches the contract monthly entries.

Confirm global revenue overview matches the sum across customers.

Mark a contract paused/ended (if supported) → confirm it stops counting toward revenue.
