# CC2-4: Switch-over (customer Contracts tab, and freeze the old contracts)

## Goal

From this release on, contracts are created, edited and renewed **only** in the Contract Center:
- The customer's Contracts tab shows the new contracts.
- The old contract screens become read-only.
- The old endpoints refuse writes.

**Randy merges and publishes this only after fixing the old data.** He runs the Copy (Settings › Contracts) right after publishing, so nothing changes in the old tables between the copy and the freeze.

Dashboard, revenue, reports, tickets, snow events and the crew app keep reading the old tables until Phase 4 re-points them. Freezing the old tables means those screens keep showing the copied state, and **contracts created after this release won't appear on them until Phase 4**. Phase 4 should follow soon.

## 1. Block writes to the old contract tables (server)

Each of these endpoints in `artifacts/api-server/src/routes/routes.ts` must return **409** with `{ message: "Contracts are managed in the Contract Center now." }` before doing any work. Put the check first, after authentication:

- `POST /api/customers/:customerId/contracts`
- `POST /api/contracts`
- `PATCH /api/contracts/:id`
- `DELETE /api/contracts/:id`
- `POST /api/contracts/:contractId/services`
- `PATCH /api/contracts/:contractId/services/:serviceId`
- `DELETE /api/contracts/:contractId/services/:serviceId`
- `PUT /api/contracts/:contractId/monthly-amounts`
- `POST /api/contracts/:contractId/documents/upload-url`
- `POST /api/contracts/:contractId/documents`
- `DELETE /api/contracts/:contractId/documents/:docId`
- `POST /api/contract-builder/documents/:id/publish-and-create`
- `PUT /api/customers/:customerId/rate-sheet`

Before editing, search `routes.ts`, `storage.ts` and the other route files for any other caller that inserts into or updates `contracts`, `contract_services`, `contract_monthly_amounts`, `contract_documents` or `customer_rate_sheets`. Report each one you find.
- If it's reachable from a user action, block it the same way.
- `autoPopulateServicePlansFromContract` only runs from those endpoints, so it stops on its own; leave the function in place.

Every GET stays as it is.

Use a single helper, `rejectLegacyContractWrite(res)`, so Phase 7 can find every call site.

## 2. Customer page (`artifacts/highplains-crm/src/pages/CustomerDetail.tsx`)

**Contracts tab** (`TabsContent value="contracts"`):
- **At the top**, the customer's Contract Center contracts (`GET /api/contract-center/contracts?customerId=`), as cards:
  - LineBadge, form, StatusPill, season and dates, annual price, the "Up for renewal" pill when due
  - an **Open** button to the contract page
- **New contract** goes to `/dashboard/contracts/new?customerId=<id>`. It's shown to admin and office.
- **Empty state:** "No contracts yet."
- **Below**, a collapsed section **"Old system (read-only)"** containing the existing `ContractCard` list. In it:
  - The upload, replace, edit and delete controls are removed.
  - Version history and document download still work.
  - There's a line: "These records were copied into the Contract Center on <date of the first copy, or 'not yet copied'>." The date is the earliest `term_legacy_sources.created_at` for the company. Add `GET /api/contract-center/copy-status`, which returns `{ firstCopiedAt, copiedContracts }`.
- **Remove the old Add Contract dialog and its mutation.**

**Billing tabs:**
- **Rate sheet:** read-only, with the note "Rates now live on each contract in the Contract Center."
- **Revenue and Monthly summary:** no change in this slice. They're read-only views of the frozen data until Phase 4.
- `ContractServices` and `ScheduleSummary`: hide the add, edit and delete controls. Viewing still works.

## 3. Other places that create contracts

- **Tools page:** hide the Contract Builder tile. The route stays until Phase 7.
- **The old `ContractsOverview`** at `/dashboard/contracts/old`: remove any create or edit controls, and add a banner: "Old system (read-only). Use the Contract Center."

## 4. Tests

- Route tests (with `../db` mocked) for each blocked endpoint: an admin gets 409, and no insert, update or delete is called.
- A render test for the customer Contracts tab: new contracts are listed first, and the old section is collapsed with no edit controls.

## Verify (development)

1. Run the Copy in development. The customer Contracts tab shows the copied contracts at the top, and the old cards under "Old system (read-only)".
2. Creating a contract the old way isn't possible from any screen, and calling the old endpoints directly returns 409.
3. New contract from a customer page opens the flow with the customer filled in.
4. The dashboard, revenue audit and reports still load.
5. Typecheck and tests pass.
