Proposal Maker — Slice P2 (Branded PDF Generation: Cover + Scope Only) — Submit This Whole Block
Goal

Generate a clean, professional branded PDF from an existing Proposal Draft that includes the proposal header details and the Scope of Work only (no estimate PDF, no images yet).

Guardrails (What NOT to build yet)

Do not merge or append the QuickBooks estimate PDF

Do not include any photos/screenshots

Do not parse or extract data from QuickBooks PDFs

Do not add emailing, automation, templates, approvals, or versioning

Keep layout and formatting simple, consistent, and highly reliable

Requirements
1) PDF Generation Actions (on Draft Page)

Add two actions on the proposal draft screen:

Preview PDF

Generates the branded PDF and displays it in an in-app viewer (or opens in a new tab/modal, whichever is most stable)

Download PDF

Downloads the same generated PDF file

Behavior Rules

PDF generation uses the current saved draft content (not unsaved edits)

If required inputs are missing (should be rare since P1 requires them), show a clear error message

2) PDF Content (What the PDF Must Include)
Required Header Elements

Company branding header (letterhead-style)

Company name (text)

Company logo (image)

Optional: company phone/email/website (if available globally in CRM settings)

Proposal title

Proposal date

Customer name

Optional: QuickBooks estimate number (only show if provided)

Required Body

Section title: Scope of Work

Scope text exactly as entered in the draft:

Preserve paragraph breaks

Preserve simple bullets (e.g., lines starting with “-” or “•”)

3) PDF Layout + Formatting Rules (Stability First)
Page Setup

Standard paper size: Letter (8.5 x 11)

Consistent margins on all pages (no edge-to-edge content)

Typography (Simple + Professional)

Use a clean, readable font

Clear hierarchy:

Header/Title larger than body text

Section heading distinct from body text

Pagination

Must support multi-page scopes reliably

Header may appear only on page 1 or repeat each page — choose the most stable approach

Page breaks must not overlap text or clip content

“No Surprises” Rule

No dynamic layout tricks, no complex columns, no floating elements that can break with long text

Prefer predictable vertical flow layout

4) Storage (Slice P2)

The generated PDF does not need versioning yet

Choose one of the following approaches (pick the simplest stable approach):

Option A (Allowed): Generate on-demand each time Preview/Download is clicked

Option B (Allowed): Store the latest generated PDF file on the draft and replace it on regeneration

Either approach is acceptable in Slice P2.

5) Permissions

Same as Slice P1:

Admin + Office can generate/preview/download

Others: no access

Acceptance Tests

Preview PDF generates without errors and displays the document

Download PDF downloads a valid PDF that opens without corruption

Logo renders correctly and consistently

Customer name, proposal title, and proposal date render correctly

Estimate number appears only when provided

Scope formatting preserves paragraphs and simple bullets

A long Scope of Work correctly paginates across multiple pages

Repeated generation produces consistent output (no random layout shifts)

Done Definition

Users can open a proposal draft and reliably generate a polished, branded PDF that includes the proposal header and Scope of Work only, with stable formatting and multi-page support.
