Proposal Maker — Professional Visual Styling Upgrade (Submit This Whole Block)

Objective

Upgrade the Proposal PDF appearance to a premium, print-ready branded document suitable for HOA boards and professional clients. Improve visual hierarchy, branding presence, and overall polish while maintaining high readability and reliability.

⸻

Design Principles (Must Follow)
	•	Clean, formal, corporate appearance
	•	Strong but tasteful branding
	•	High readability (print and screen)
	•	Generous whitespace
	•	No decorative clutter
	•	No layout elements that risk text overlap
	•	Output must remain deterministic and stable

⸻

Page Setup
	•	Paper size: Letter (8.5 × 11)
	•	Margins: Consistent on all sides (minimum 60 pt)
	•	Vertical flow layout only (no columns or floating elements)

⸻

Company Header (Letterhead Style)

Place at the top of the first page.

Logo
	•	Centered or left-aligned (choose one consistently)
	•	Prominent but not oversized
	•	Fixed width equivalent: ~140–180 px
	•	Maintain clear spacing below (minimum 24–36 pt)
	•	Text must never overlap the logo

Company Name
	•	Display below or beside logo
	•	Bold font
	•	Use primary brand color
	•	Centered if logo is centered, left-aligned if logo is left-aligned

Optional Contact Line (if available)
	•	Phone / Email / Website in small muted text

⸻

Watermark / Background Graphic

Apply a subtle full-page watermark.

Theme
	•	Landscape-appropriate design (e.g., mountain silhouette, topographic lines, tree line, subtle natural texture)

Constraints
	•	Very low opacity (approximately 3–8%)
	•	Must not reduce readability
	•	No repeating tile patterns
	•	No bright colors
	•	Must print cleanly in grayscale
	•	Positioned behind all content
	•	Never overlap in a way that obscures text

⸻

Title Section

Proposal Title
	•	Large, bold text
	•	Use primary brand color
	•	Left-aligned
	•	Clear spacing above and below

Add a thin horizontal divider line beneath the title in brand color or neutral gray.

⸻

Metadata Block

Display as structured labeled fields (not plain sentences).

Example layout:

Prepared For:    {Customer Name}
Proposal Date:   {Formatted Date}
Estimate #:      {Estimate Number — only if present}

Formatting:
	•	Labels in bold
	•	Values in regular weight
	•	Left-aligned
	•	Consistent spacing between lines
	•	Neutral text color (not brand color)

⸻

Section Heading — Scope of Work

Heading text:

SCOPE OF WORK

Formatting:
	•	Uppercase
	•	Bold
	•	Primary brand color
	•	Larger than body text
	•	Clear spacing above and below
	•	Thin divider line beneath

⸻

Body Text (Scope Content)
	•	Font size approximately 10–11 pt equivalent
	•	Dark gray or black text
	•	Left-aligned
	•	Slightly increased line spacing for readability
	•	Preserve paragraphs exactly as entered
	•	Preserve simple bullets
	•	Do not use colored body text

⸻

Divider Lines

Use thin horizontal rules to structure sections:
	•	After header
	•	After title block
	•	Optional above footer

Color: neutral gray or brand accent color
Thickness: thin and unobtrusive

⸻

Footer

Include on all pages.

Contents (if available):
	•	Company name
	•	Contact information or website
	•	Page number

Formatting:
	•	Small font
	•	Muted gray color
	•	Centered or right-aligned
	•	Thin divider line above footer (optional)

⸻

Appendix Pages (Images)

Maintain current behavior with the following styling:
	•	New section header: PROJECT IMAGES
	•	Same heading style as Scope section
	•	One image per page
	•	Image centered and scaled to fit within margins
	•	Caption below image in muted text
	•	Maintain fixed caption position to prevent overlap

⸻

Color Usage Rules
	•	Use brand colors only for:
	•	Logo
	•	Title
	•	Section headings
	•	Divider accents
	•	Body text must remain dark gray or black
	•	Avoid multiple accent colors
	•	Avoid colored backgrounds

⸻

Layout Safety Rules
	•	No text wrapping around images or logo
	•	No dynamic repositioning that could cause overlap
	•	Maintain predictable vertical flow
	•	Must handle multi-page documents reliably
	•	Output must remain identical for the same inputs

⸻

Acceptance Criteria
	1.	Document appears professional and print-ready
	2.	Logo is prominent but does not interfere with text
	3.	Watermark is visible but subtle and non-intrusive
	4.	Brand colors applied consistently and tastefully
	5.	Metadata is cleanly structured and easy to scan
	6.	Scope text remains highly readable
	7.	No layout breakage on multi-page scopes
	8.	Image appendix remains clean and consistent
	9.	PDF renders correctly across common viewers

⸻

Done Definition

Generated proposals present as polished, branded professional documents appropriate for formal client delivery, significantly improving visual quality without compromising reliability or readability.
