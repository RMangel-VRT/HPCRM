## 2. The new component must be its own `.tsx` file

Your relevant-files list includes `shared/ticketVisuals.ts` but not a new component file,
which reads like the identity primitives might go into `ticketVisuals.ts`. They cannot.

`shared/ticketVisuals.ts` is a **`.ts` file with no React import and no JSX** — it is a
pure vocabulary module deliberately kept renderer-free so server-adjacent code can read
it. Adding components would force a rename to `.tsx` and drag React into a module that
has no business importing it.

**Create `artifacts/highplains-crm/src/components/TicketIdentity.tsx`** as the slice
specifies. `ticketVisuals.ts` is **read-only** in this slice — it is imported, never
edited. Same for `index.css`: Step 1 verifies `--tt-on-hue` exists in both `:root` and
`.dark`; it adds nothing.
