Add a new Ticket Type: RFP Request

Purpose: Track the full lifecycle of a community requesting a proposal for maintenance services, from first contact through award and onboarding into the CRM.

This is a process ticket (multi-step), not a simple task.

1) Ticket Type Definition (RFP Request)

Ticket Type Name: RFP Request

Ticket Work Type (classification): Admin (non-billable)

Workflow Style: Step-based pipeline with required fields at each step

Who can create: Admin / Office

Who can view: Admin / Office / Ops / Viewer (Ops/Viewer read-only)

Who can update status:

Admin / Office: can move through all steps

Ops: can add notes/photos when assigned steps allow it (optional)
