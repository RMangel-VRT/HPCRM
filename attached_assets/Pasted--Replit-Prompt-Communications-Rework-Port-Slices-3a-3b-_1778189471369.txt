# Replit Prompt — Communications Rework, Port Slices 3a/3b/3c/4 into the pnpm Multi-Artifact Workspace

## Context

The repo was restructured into a pnpm multi-artifact workspace in commit `84b25ec` ("Port High Plains CRM to pnpm multi-artifact workspace"). After that restructure, all live code lives under:

- `artifacts/highplains-crm/` — the deployable web app (Vite + React)
- `artifacts/api-server/` — the deployable Express API
- `artifacts/highplains-mobile/`, `artifacts/mockup-sandbox/` — other artifacts
- `lib/db/` — shared Drizzle schema, consumed by the api-server as `@workspace/db`

The old `client/`, `server/`, and `shared/` trees were moved to `.migration-backup/` and are **not** part of `pnpm-workspace.yaml`. Anything written there is dead code that does not ship.

Four Communications Rework slices ran across the restructure and **never reached the live workspace**. Their code is currently scattered across:

- `client/src/pages/communications/*.tsx` (top-level `client/`, NOT in the workspace)
- `.migration-backup/client/src/pages/CommunicationsCenter.tsx` (the new shell-based wrapper)
- `.migration-backup/client/src/components/AppSidebar.tsx` (post-Slice-4 sidebar)
- `.migration-backup/server/routes/unsortedEmails.ts` (Slice-4 backend additions)

The deployable artifact still has the legacy 2,375-line monolithic `artifacts/highplains-crm/src/pages/CommunicationsCenter.tsx` and a sidebar with two separate "Communications" + "Inbox" entries.

The four affected slices:

- **Slice 3a (Task #331)** — Page shell + secondary nav. Created `CommunicationsPageShell`, `CommunicationsSecondaryNav`, and the initial `AllCommunicationsTab` (the legacy monolith content moved into a tab).
- **Slice 3b (Task #332)** — Extracted `UnsortedTab` component (already reachable in the live artifact at `artifacts/highplains-crm/src/components/customer/communications/UnsortedTab.tsx` — the shell-based CommunicationsCenter wraps it).
- **Slice 3c (Task #333)** — `InboxTab` and `SentTab`.
- **Slice 4 (Task #334)** — Routing, sidebar merge, Compose button, focus deep-link, observability logging, `resolvedToday=true` filter, "all caught up" empty state.

This prompt ports all of that work into the live artifacts. It is a **mechanical port plus rewiring**, not a redesign. The component code in `client/src/pages/communications/*.tsx` and the wrapper in `.migration-backup/client/src/pages/CommunicationsCenter.tsx` should be moved with minimal edits — only what's needed to compile under the new workspace.

This must land in a deployable, production-quality state. After the port, `client/src/pages/communications/` should be deleted so it can never drift from the live copy again.
