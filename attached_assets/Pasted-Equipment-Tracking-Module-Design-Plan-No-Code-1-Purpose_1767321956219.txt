Equipment Tracking Module — Design Plan (No Code)
1) Purpose

Create a centralized equipment database for High Plains that:

Stores all equipment assets (trucks, mowers, skid steers, trailers, etc.)

Tracks key identifiers and specs

Supports an Equipment Ticket workflow for maintenance/repairs

Is editable only by Admin + Shop Manager

Has its own dedicated Equipment page for viewing, searching, and filtering

2) Navigation & Permissions
New Navigation Item

Add a main nav item: Equipment

Access Rules

Admin: full access (create/edit assets, create/edit/close equipment tickets)

Shop Manager: full access same as Admin (for this module)

Office/Ops/Viewer: view-only or no access (your choice)

Recommendation:

Office = view-only (helpful for scheduling)

Ops = view-only (helpful for “which truck is mine?”)

Viewer = no access

Base Equipment Record (applies to all types)

Equipment Type (Truck, Mower, Trailer, Skid Steer, ATV/UTV, Specialty, Other Vehicle)

Name / Label (e.g., “Truck 12”, “Skid 1”, “Wright Stand-On #3”)

Status

Active

In Repair

Out of Service

Sold/Retired

Assigned To

Crew / employee (optional)

Location

Shop / Yard / In-field (optional)

Manufacturer / Brand

Model

Year

Serial / VIN (depending on type)

Purchase Date (optional)

Warranty Expiration (optional)

Notes

Attachments

Registration, insurance card, manuals, receipts, photos

6) Equipment Tickets (Maintenance / Repair Tickets)
Intent

An Equipment Ticket is the same concept as your existing ticketing system, but linked to an equipment asset instead of a customer contract.

Equipment Ticket Fields

Equipment item (required)

Ticket category (required):

Preventative Maintenance

Repair

Inspection

Safety

Breakdown (urgent)

Priority:

Low / Normal / High / Urgent

Description of issue/service needed (required)

Photos / attachments (strongly encouraged)

Reported by (auto)

Assigned to:

Shop Manager

Mechanic/vendor

Crew leader (optional)

Due date (optional)

Status Flow (Simple and shop-friendly)

New

Diagnosing

Waiting on Parts

In Repair

Completed

Closed / Verified (optional final step)

Keep it simple and consistent with how a shop actually works.

Completion Fields (required at completion/close)

Work performed notes

Labor time (optional but recommended)

Parts used (optional now; add later)

Vendor used (optional)

Final cost (optional, but valuable later)

7) Auto-Behavior & Quality-of-Life Rules

When an equipment ticket is created:

If Priority = Urgent → equipment status becomes “In Repair” automatically (optional)

When ticket is marked Completed/Closed:

Prompt to update:

Odometer/hours (if applicable)

Last service date

On each equipment item:

Show count of open equipment tickets

Show last service date and last completed ticket link

8) Reporting (MVP)

Add a basic dashboard inside Equipment:

Open tickets by status

Equipment currently “In Repair”

Equipment with most repair tickets in last 90 days (optional later)

Upcoming preventative maintenance (later when you add intervals)

9) Acceptance Tests (Before You Call It Done)

Admin can create equipment item of each type (Truck, Mower, Trailer, Skid Steer).

VIN/serial fields behave properly for each type.

Equipment list filters/search work.

Create equipment ticket from equipment detail page.

Ticket appears:

On ticket list (equipment ticket list)

On equipment detail → Tickets tab

Status changes persist and show history.

Attachments/photos work on equipment tickets.

Only Admin + Shop Manager can create/edit assets.

Office/Ops can view (if allowed), but cannot edit.
