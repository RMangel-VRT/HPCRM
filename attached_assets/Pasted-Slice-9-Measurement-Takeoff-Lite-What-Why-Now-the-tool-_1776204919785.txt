Slice 9 — Measurement + Takeoff Lite
What & Why

Now the tool looks professional and exports cleanly — but it’s still purely visual. This slice introduces practical utility by adding lightweight measurement and quantity awareness.

The goal is NOT to turn this into CAD or GIS. The goal is to give you:

quick area estimates (mulch, rock, turf conversions)
linear footage (edging, paths, drip runs)
counts (trees, boulders, irrigation components)

This directly ties into your real workflows:

proposals
rough budgeting
scope validation
internal planning
Scope
Add area calculation for polygons (when scale is known)
Add linear measurement for polylines (when scale is known)
Add symbol counts
Add label display toggles for measurements
Add basic summary output (takeoff-lite)
Add scale handling system
Critical Concept — Scale Awareness

This slice only works if we properly handle scale.

Two Modes:
1. Scaled Mode (Satellite Capture)
Mapbox-based images can be considered scale-aware
You can calculate:
square feet
linear feet
2. Non-Scaled Mode (Manual Upload)
No reliable scale
Measurements must be:
disabled OR
labeled clearly as “Not to Scale”
Requirements
Area Measurement (Polygons)
Automatically calculate area for each polygon (if scaled)
Store value in:
square feet (primary)
Allow display:
on-canvas label (toggle)
inspector panel
Optional: round values for readability
Linear Measurement (Polylines)
Calculate total length of line (if scaled)
Store value in:
linear feet
Allow display:
on-canvas label (toggle)
inspector panel
Symbol Counts
Count instances per symbol type
Store as:
grouped totals (e.g., 14 trees, 6 boulders)
Feed into:
legend (optional count display)
future takeoff summary
Measurement Labels
Toggle per object:
show/hide measurement
Label style:
subtle
readable
non-intrusive
Example:
“2,450 SF”
“185 LF”
