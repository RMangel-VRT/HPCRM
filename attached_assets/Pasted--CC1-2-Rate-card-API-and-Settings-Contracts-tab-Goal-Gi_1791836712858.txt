# CC1-2: Rate card API and Settings › Contracts tab

## Goal

Give the company one rate card. Every new contract and renewal will start from it (Phase 2), and the estimate builder's labor rates should later read from the same list. This slice adds endpoints and a Settings tab to view, edit and seed it. Nothing reads the rate card yet.

Depends on CC1-1 (`rate_card_items` table and `RATE_CARD_DEFAULTS` in `contractCatalog.ts`).

## Server: `artifacts/api-server/src/routes/contractCenter.ts` (new file)

Create the file, export `registerContractCenterRoutes(app: Express)`, and call it in `registerRoutes()` on the line after `registerDashboardQueueRoutes(app);`. Use `db` from `../db` and tables from `@workspace/db`, like `routes/flags.ts`. Use static imports only.

Auth helpers at the top of the file:
- `adminOrOffice(req, res)`: copy the pattern from `routes/flags.ts`. 401 if not signed in; 403 unless `activeRole` is `admin` or `office`, or the user `isSuperAdminBool`.
- `adminOnly(req, res)`: the same, but only `admin` or `isSuperAdminBool`.

Every query is scoped by `user.activeCompanyId`.

| Method and path | Who | Does |
| --- | --- | --- |
| `GET /api/contract-center/rate-card` | admin, office | All rows for the company, ordered by `line`, `sort_order`, `label`. Includes inactive rows with `active: false`. |
| `POST /api/contract-center/rate-card/seed-defaults` | admin | Inserts every `RATE_CARD_DEFAULTS` entry whose `rate_key` the company doesn't already have, using `ON CONFLICT (company_id, rate_key) DO NOTHING`. `sort_order` = index in the defaults list. Never overwrites an existing row. Returns `{ inserted: n, skipped: m }`. |
| `POST /api/contract-center/rate-card` | admin | Adds a custom rate. Body: `rateKey`, `line`, `category`, `label`, `priceCents`, `priceText`, `unit`, `minimum`. `rateKey` must match `/^[a-z][a-z0-9_]{1,62}$/`; 409 if the company already has it. |
| `PATCH /api/contract-center/rate-card/:id` | admin | Updates `label`, `category`, `priceCents`, `priceText`, `unit`, `minimum`, `sortOrder`, `active`. **`rateKey` and `line` are not accepted** (strip them before parsing; a body containing only those returns 400 "Nothing to update"). Use `pickProvided` so absent keys are never written. 404 if the row isn't in the company. Sets `updated_at = now()`. |

No DELETE. Retiring a rate sets `active: false`, because terms will refer to rates by key.

Validation:
- `priceCents`: integer ≥ 0 or `null`.
- `priceText`: up to 60 characters or `null`.
- `unit`: 1–80 characters.
- `minimum`: up to 40 characters or `null`.
- `line`: `RATE_LINES`.
- A row must have `priceCents` or `priceText` unless it's one of the "set per contract" rows. Allow both to be null; the UI shows "Set per contract".

Tests go in `artifacts/api-server/src/routes/contractCenter.test.ts`. Follow `dashboardQueue.test.ts`: it registers the routes on a bare express app with supertest and **mocks `../db`**. Test what lives in the route:
- Office can GET and gets 403 on seed, POST and PATCH; field roles get 403 on GET.
- The seed insert contains all 22 default keys and uses `onConflictDoNothing` on `(company_id, rate_key)`.
- PATCH with `{ rateKey: "x", priceCents: 100 }` passes only `priceCents` (plus `updatedAt`) to `.set()`.
- PATCH `{}` and PATCH `{ rateKey: "x" }` return 400 without calling `.update()`.
- The update's where clause includes the company id.

Seed idempotency and "doesn't overwrite an edited price" depend on the real database, so check them by hand (Verify, step 4).

## Client: Settings › Contracts tab

In `artifacts/highplains-crm/src/pages/SettingsPage.tsx`:
- Add `"contracts"` to `validTabs`.
- Add a `TabsTrigger value="contracts"` (label "Contracts") inside the `isAdmin` group, right after the Service Plans trigger.
- Add a `TabsContent value="contracts"` rendering `<ContractSettings />`.

Office users don't get the tab in this phase. They see rates on each contract in Phase 2.

New component `artifacts/highplains-crm/src/components/contracts/ContractSettings.tsx`. Use the same building blocks as `ServicePlanTemplatesAdmin.tsx`: `useQuery`/`apiRequest`/`queryClient`, shadcn `Card`, `Input`, `Switch`, `useToast`, `extractApiErrorMessage`.

1. **Rate card card.**
   - **Header:** title "Rate card" and one line: "Every new contract and renewal starts from these rates. Signed contracts keep the rates they were signed with."
   - **Empty state** (no rows): "No rates yet." and a primary button **Load High Plains standard rates**, which POSTs `seed-defaults`. After seeding, show a toast: "Loaded 22 standard rates" (use the returned count).
   - **Table**, grouped by line (Landscape, Irrigation, Snow, General), then by category. Columns: Rate, Price, Unit, Minimum, Active.
     - **Price** is a dollar input. Show and edit dollars (two decimals); send cents (`Math.round(value * 100)`).
     - A row with `priceText` (the holiday rate) shows that text in a text input instead.
     - A row with neither shows a muted "Set per contract" placeholder.
   - **Editing:** changes save on blur, one PATCH per changed field. Show a small "Saved" toast; on error, show the server message and revert the input.
   - When seeded rows exist but some default keys are missing (a later release adds defaults), show a quiet **Add missing standard rates** link that calls the same seed endpoint.
   - **Add rate:** a small inline form (key, line, category, label, price, unit, minimum) for one-off company rates.
2. **"Coming next" card**, muted. Contains: "Word master and scope presets arrive with the Contract Center screens."

Use dollars-with-cents formatting everywhere (`$1.45`, `$245`); never show raw cents.

## Verify

1. As admin: Settings › Contracts shows the empty state.
2. Load the standard rates: you get 22 rows. The snow rows read:
   - Service truck $120 per occurrence
   - Plow truck $145 per hour, 3 hour minimum
   - Skid loader $245 per hour, 3 hour minimum
   - ATV / snowblower $135 per hour, 3 hour minimum
   - Hand shovel $80 per hour, 6 hour minimum
   - Ice melt application $70 per hour
   - Holiday rate 1.5x Normal Rates
   - Ice melt $1.45 per pound, 50 lb minimum
   - Sand / salt mix $105 per ton
   - Snow stakes $5.00 per stake installed
3. The four labor rows show "Set per contract".
4. Change Skid loader to $250 and reload: it shows $250. Click "Add missing standard rates": still $250.
5. As office: no Contracts tab. Calling `PATCH /api/contract-center/rate-card/:id` directly returns 403.
6. Typecheck and tests pass.

## Not in this slice

Anything that reads the rate card (contracts, renewals, estimates), Word master upload, scope presets, and any change to `customer_rate_sheets` or Billing › Rate sheet.
