# Navigation slices

**How to use them in Replit:**
1. Paste `00-RULES-N.md` once at the start of the session.
2. Paste the slices **one at a time, in order**. Merge each one before pasting the next.

| File | What it does | Schema? |
|---|---|---|
| `00-RULES-N.md` | The rules every slice follows | — |
| `N1-shell-and-sidebar.md` | Every role gets the desktop sidebar; new groups; Tools and New menus; profile menu; Operations broken up; crew supervisors get a working web page | No |
| `N2-section-rail-and-settings.md` | The light-green section rail; Settings on the rail; Seasons merged into Settings | No |
| `N3-rail-across-pages.md` | The rail on Tickets, Maps, Campaigns, Plant Library, Inbox and Flags; the customer page restyled | No |
| `N4-invoicing-renames.md` | Billing → Invoicing; "Ready for Billing" → "Ready to invoice" (label only) | DML only |
| `N5-estimates-board.md` | A new Estimates board of open bids by stage | No |

**Design:** the "High Plains Navigation Model" artifact, and `claude/navigation-design.md` in the Claude project.
