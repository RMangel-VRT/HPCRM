# FIX: Compact, collapsible renewals board

Small standalone UI fix to the Contract Center page. **No API, schema or migration changes.** It can run alongside CC2-6 and CC2-7.

**Line numbers are from GitHub `b551d41`**; find code by its content. Files touched:
- `artifacts/highplains-crm/src/pages/ContractCenterPage.tsx`
- `artifacts/highplains-crm/src/components/contracts/boardLogic.ts`
- their tests

**If CC2-7 has already merged,** keep everything it added to the board card and the table, such as the parent's "· N locations" suffix. Fold it into the new compact layout; don't drop it.

## The problem

Now that every contract has been imported, the renewals board (`ContractBoard`) takes up the whole screen. Up for renewal alone has 8 cards at about 100px each, and the All contracts table is pushed below the fold. Two things cause it:
- each card is four stacked rows plus a separate button row
- the columns grow without limit

## 1. Collapsible board

In `ContractBoard`, wrap the columns in a collapsible section. The header row stays visible at all times:

- **Header row (always shown):**
  - A toggle button (`data-testid="button-toggle-board"`) with a `ChevronDown` icon that rotates −90° when collapsed, and the label **Renewals**.
  - `aria-expanded` set to the current state, and `aria-controls` pointing at the board's id.
  - Next to it, a one-line summary with these counts (`data-testid="text-board-summary"`):
    - "{n} up for renewal"
    - "{n} sent"
    - "{n} signed"
    - "{n} lost"

    Use the same counts the columns show. Separate them with " · ", and render each zero count in muted text.
  - The existing "{x} of {y} renewals signed" text and progress bar move into this header row, on the right on wide screens and on their own line below on narrow ones. Keep `data-testid="renewal-progress"` and `text-renewal-progress` exactly as they are.
- **Body:** the four columns, shown only when expanded. Put `id="renewals-board-body"` on the wrapper and keep `data-testid="renewals-board"` on the columns row.
- **Remembered state:**
  - Store the open/closed state in `localStorage` under `hp-contract-center-board-open` (`"1"` or `"0"`). Default is open.
  - Wrap reads and writes in try/catch, the same way `readBoard()` does.
  - Read it once on mount with a lazy `useState` initializer.
- **Search overrides collapse.** When the search box has text and the board is collapsed, show the summary counts for the search. If any count is above zero, add a "Show" link that expands the board. Don't auto-expand.

`ContractBoard` keeps its current props. Add an optional `defaultOpen?: boolean` prop for tests; when it's given, it overrides storage.

## 2. Columns scroll on their own

- Cap each column's card list (the `div.space-y-2` inside each `section`) at **`max-h-[26rem]` with `overflow-y-auto`**, plus a little right padding (`pr-1`) so the scrollbar doesn't cover the cards. With the compact cards from §3, that's about four cards.
- The column title and count stay fixed above the scrolling list.
- When a column has more cards than fit, show a faint fade at the bottom of the list as a hint that it scrolls. Use a `pointer-events-none` gradient from transparent to the column background, and only show it while the list overflows and isn't scrolled to the bottom. A small `useLayoutEffect` with `onScroll` is enough; no new package.
- Columns stay equal width (`flex-1 min-w-[17rem]`) with the existing horizontal scroll on narrow screens.

## 3. Compact cards

Rewrite `BoardCardView` as two rows. Keep **every existing `data-testid`** (`card-…`, `text-card-customer-…`, `button-renew-…`, `link-open-…`, `text-renewal-state`):

- **Row 1:** `flex items-center gap-2`
  - Customer name: `font-medium text-sm truncate flex-1 min-w-0`, with `title` set to the full name.
  - Price: `text-sm tabular-nums whitespace-nowrap`, from the same `priceLabel(...)`.
  - The action, made smaller:
    - Renew: `size="sm"` with `className="h-7 px-2.5 text-xs"`
    - Open: an outline button of the same size
- **Row 2:** `flex flex-wrap items-center gap-x-2 gap-y-1 text-xs`
  - `LineBadge`, the form text and `StatusPill`
  - the drafted state, the renewal chip and the review chip, using the same conditions as now
  - then muted text "{seasonLabel} · ends {date}"
- Card padding goes from `p-3 space-y-2` to `px-3 py-2 space-y-1.5`.
- The whole card isn't a link; only the button acts. Don't change any hrefs.

## 3a. Light-mode contrast on the board

Dark mode reads well, but in light mode the page, the columns and the cards are nearly the same white:
- the page `--background` is at 100% lightness
- `bg-muted/40` puts the columns at about 97%
- `--card` puts the cards at 98%
- the border (`--border`, 88%) is the only thing separating a card from its column

The mountain background art also shows through the translucent columns. Fix it **on the board only** with `dark:` variants, so dark mode stays exactly as it is:

- **Column:** `bg-muted/80 dark:bg-muted/40`, plus `border border-border/70 dark:border-transparent`. The column becomes a visible light-grey tray, and it's opaque enough to hide the background art.
- **Card:** `bg-background dark:bg-card`, so cards are pure white on the grey tray in light mode and unchanged in dark. Add `shadow-sm dark:shadow-none`, and use `border-border` with `hover:border-foreground/20` so the card under the pointer is clear.
- **Column title row:** move the count into a small pill (`rounded-full bg-background dark:bg-muted px-1.5 text-xs`) so the headings separate from the tray.
- **The fade from §2** uses the column's own background in each mode (`from-transparent to-muted/80 dark:to-muted/40`), so it matches the tray.

**Don't change the theme tokens in `index.css`.** They're used across the whole app. A global light-mode contrast pass is a separate decision.

## 4. Lost column: last 90 days, plus "View all"

The windows in `placements()` (`boardLogic.ts`) are currently:
- **Signed:** signed in the last 60 days. Keep this.
- **Lost:** ended in the last **12 months**. Change it to **90 days** (`addDays(today, -90)`), and update the empty text to "No contracts lost in the last 90 days."

Then add a way to see the rest:
- Add a **Lost** filter chip to the All contracts table (`FilterChip` gains `"lost"`; it matches `rowTerm(i)?.displayStatus === "lost"`, or `status === "lost"` if that's the field the table reads). Put it after Expired, with `data-testid="chip-filter-lost"`.
- Under the Lost column's list, add a small "View all lost" link button (`data-testid="link-view-all-lost"`). It turns on only the Lost chip in the table and scrolls the table into view (`scrollIntoView({ behavior: "smooth", block: "start" })`).
- To make that work, lift the table's `chips` state up to `ContractCenterPage` and pass it to `ContractTable` as `chips` / `onChipsChange`.
- `ContractTable` must still work standalone in tests. Keep internal state when `chips` isn't passed.
